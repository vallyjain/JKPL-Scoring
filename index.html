Scoring rules used by this app

Traditional international pickleball side-out scoring is used: only the serving team scores a point.

Doubles serving starts at 0-0-2, then each team normally has server 1 and server 2 before side out.

Games must be won by 2. A match winner is recorded after enough rounds are won for the match format.

The point buttons award a rally to that team. If the receiving team wins a rally, the app changes server or side-out instead of adding a point.
